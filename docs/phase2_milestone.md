# Phase 2 Milestone — Parametric Skeleton Sketch (2026-06-11)

## 完成内容

从零构建了参数化 3D 骨架草图编辑器（web3/），替代了 Phase 1 的 Web 可视化工具和 Phase 2 迭代 1 的生长动画工具（web2/）。

## 核心设计

### 参数化草图而非动画播放

web2 的核心是"生长动画"——逐步播放骨架构建过程。用户反馈后转为 web3 的"参数化草图"：

- 初始即展示完整骨架
- 所有尺寸标注（距离、角度）可直接双击编辑
- 编辑后系统按隐含的生长依赖关系重新计算全部位置
- 动画功能降级为辅助功能（暂未实现）

### 生长依赖模型

每个骨架节点定义为一个生长步骤：
```
{ name, parent, label, params, annotations, build(params, parentPos) → { pos } }
```

- `parent` 确定依赖关系（树状）
- `build` 从父节点位置 + 全局参数计算自身位置
- `params` 定义该步骤控制的参数（带范围、默认值、单位）
- 参数在全局 `params` 对象中扁平化，多步骤可共享参数

### 可编辑标注

三种标注类型，均为 HTML overlay（3D→2D 投影定位）：
1. **dim**（距离）：线段中点偏移处，橙色，如 `L_AT = 7mm`
2. **angle**（角度）：角平分线方向，蓝色，如 `alpha = 35°`
3. **circle_r**（圆半径）：圆边缘，橙色，如 `R = 16mm`

双击标注 → 内联 input 编辑 → Enter 确认 → `rebuildScene()` 重建整个场景。

### 虚实区分

- **实线（圆柱体）**：手指骨架结构线
- **虚线（LineDashedMaterial）**：舵机辅助线（S→Sz→C/E）
- **虚线圆**：舵机运动范围
- **半透明面**：舵机平面（10×10mm），无边框

### 高亮交互

- 点击树节点或 3D 球体 → 高亮对应元素（放大、变色）
- 其余元素变淡
- 再次点击取消选择

## 技术栈

- Three.js r170（本地 vendored，ES module）
- OrbitControls（Z-up 坐标系）
- 纯静态文件，`python -m http.server` 即可运行
- 无构建工具，无框架

## 骨架状态（截至当前）

已定义 14 个生长步骤，15 个参数：

**舵机侧**：Origin → S（舵机面）→ Sz → C/E（双舵机中心）→ D/F（力臂端点，β₁ 控制）

**手指侧**：Origin → B（基座）→ P（枢纽）→ 分三路：
1. Q → U（+Z 延伸）
2. A → T（角度线）→ R/L（横杆）
3. A → R'（相对 TA 角度线）
